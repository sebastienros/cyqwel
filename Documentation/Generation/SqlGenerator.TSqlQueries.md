# Generation / SqlGenerator.TSqlQueries.cs

Partial of `SqlGenerator` (see `SqlGenerator.md`).

Writers for T-SQL query extensions: table hints (`WITH (NOLOCK)`), index references, `TABLESAMPLE`, table functions, `OPENJSON ... WITH (...)` columns, `PIVOT`/`UNPIVOT`, parenthesized tables, derived mutation tables, `CROSS/OUTER APPLY`, `OPTION (...)` query options and `FOR JSON` / `FOR XML` result formats.
